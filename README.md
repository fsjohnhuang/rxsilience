# Rxsilience

A lightweight TypeScript library for frontend resilience and data mapping.

- ⚖️ Load Balancing: Client-side request distribution (Ribbon-style).
- 🛡️ Service Degradation: Graceful fallbacks for failing services.
- 🔄 Data Mapping: Automatic transformation from Server DTOs to Client VOs.
- 🧬 Type Conversion: Built-in encoding/decoding and data type coercion.
